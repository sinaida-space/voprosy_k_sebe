# VOPROSY K SEBE

An interactive guide in Russian to solving creative problems, from the first question to a finished idea. It covers nine thinking methods, six creative blockers and protocols for working with AI as a co-author. The page has an animated particle background.

## Open it

https://sinaida-space.github.io/voprosy_k_sebe/

It is a single static page: open `index.html` in a browser.
